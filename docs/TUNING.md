# Round 2

Round 2 (Zaratan, torch 2.14.1+cpu): one navigation-improvement round on top of round 1's choices, applied identically to every method: the convolutional Q-network, then (on the winning architecture) shaping with Φ = −d instead of −4·d/d_max. A change is kept if **dev success** (round 1's definition: familiar + clutter pooled, 226 episodes per seed, mean over seeds) rises >= 2 pp for highest_q@cf. If a change is kept, the same value_penalty and fabr_v2 grids are re-run at the new settings; otherwise round 1's values stand. Shaping already used BFS shortest-path distance around walls.

**Selected:** `{"train": {"lr": 0.0001, "n_step": 3, "capacity": 10000, "epsilon_fraction": 0.8, "pool_size": 100, "pool_seed": 7, "shaping_scale": 4.0, "window": 100}, "steps": 100000, "value_penalty": {"penalty": 10.0}, "fabr_v2": {"margin": 1.0, "margin_lambda": 0.1, "margin_stop_grad": false}, "carried_from_round1": ["value_penalty", "fabr_v2"]}`
